# Historical and supporting source archive

These snapshots are not workflow entry points. Paths were replaced by symbolic placeholders; source SHA256 values refer to the private/original bytes, not these sanitized copies. The former public layout is retained here rather than silently discarded. It includes two known parse defects (an accidental console launcher and a comma in the anthropogenic-variable exploratory script).

`local_analysis/` contains actual local GloNAF and draft SEM/preprocessing scripts. Final submitted-use is unresolved. `exploratory/` contains code fragments only, without private discussion. `hpc_supporting/` describes later 813-taxon aggregation and non-native masking products; it requires external manifests/intermediates and is not a replacement for the submitted response raster. See [archive manifest](../metadata/archive_manifest.csv) and [inventory](../metadata/code_integration_inventory.csv).
