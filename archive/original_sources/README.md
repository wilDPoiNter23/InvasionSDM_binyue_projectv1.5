# Recovered source inspection snapshots

Full local and live-HPC source bodies are preserved here. Private machine/account locators are replaced by public path placeholders. UTF-8 public snapshots are not byte-identical original bytes; original SHA-256 and safe-public SHA are recorded in metadata/source_recovery_manifest.csv. Private raw originals remain outside Git.

Diagnostics and downstream calculations were not shortened. Later HPC implementations remain separate from submitted analyses. Hash-prefixed HPC filenames deduplicate identical sources; every original location has a public root-alias manifest row.

Snapshots are for inspection, not execution with placeholder paths. Seven damaged R originals are full .R.txt snapshots, with escaped corruption markers where needed. No invented analysis or silent scientific repair replaces them. Source recovery authorizes no remote deletion.
