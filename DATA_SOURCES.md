# External data sources

No input dataset, raster, polygon or model object is included. Expected paths are relative to aliases in config/config.example.R. Processing target is generally 2.5 arcmin (1/24 degree); native input resolution is separately stated where known. Filename years are labels, not independently verified acquisition dates. Dataset DOIs/releases/licences not established by the authorized source evidence are marked **TO VERIFY**; links or generic provider names are not dataset citations.
