# HPC SDM reference workflow

This is the available public batch implementation, cleaned for paths/setup while retaining numerical expressions. Its equivalence to every historical submitted model is unproven. Do not treat its settings as the realized settings of all species; read the species metadata and audit first.

1. Put the external species list at HPC_INPUT_ROOT/script/output/species_list.csv (`species` column). Put the external aligned stack at HPC_INPUT_ROOT/climate/full_stack.tif. Occurrence files are WORK_ROOT/data/species_occ/{underscore_taxon}/{underscore_taxon}_occurrences.csv. Confirm columns from source and the preserved cache/version expectations.
2. Configure the private path file, export INVASIONSDM_PROJECT_ROOT and INVASIONSDM_CONFIG, install the listed packages separately. Historical package versions are not locked or certified. `metadata/runtime_dependencies.csv` inventories package and I/O calls.
3. One species is processed inside a batch loop: load records, select species-specific variables, thin/format PA data, build GLM/RFd/MAXNET candidates, evaluate/select ensemble or fallback, and project. Existing projection/formatted/environment/model files can skip steps. Such reuse needs independent provenance/QC; it is not automatically accepted because a file exists.
4. This reference has 29 species per batch. Number of batches is ceiling(number of species / 29). An individual-species rerun therefore needs a one-row supplied species list and batch 1; do not edit scientific filters for convenience. Do not run a replacement list into a directory containing conflicting cached products.
5. Copy/edit [Slurm template](../slurm/batch.example.sh), specify your resources/account/partition and appropriate array bounds, and create logs before submission. Example (only after author-confirmed inputs): `sbatch --array=1-N code/04_sdm/slurm/batch.example.sh`. The repository does not submit this command itself.
6. Outputs live under WORK_ROOT: data/species_formatted and data/environmental caches; models/{species}; results/individual_models, ensemble_models, projections, evaluations, variable/correlation and variable/select; logs/temp. MODEL_ROOT/RESULT_ROOT should correspond to this source tree.
7. Global projection is part of fit_and_project_batch.R and uses selected/fallback objects. Some later repair/projection variants are archived, not interchangeable with this stage.
8. The [index reference](../../05_projection_and_index/build_multispecies_index.R) requires a projection-summary table plus saved projection objects and rasters. It normalizes species separately, handles NA as zero, and uses its success count. It is not proven to write the submitted normalized2.0 raster. The exact immutable contributor list/writer/mask must be recovered before an exact historical reproduction is claimed.

No model jobs or scientific calculations were run during this integration. The Slurm resources are example operational settings; they do not alter the R source's numerical/core settings.
